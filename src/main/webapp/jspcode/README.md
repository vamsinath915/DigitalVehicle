Digital Vehicle Information System
---
Description
The Digital Vehicle Information System is an integrated web-based solution that centralizes vehicle-related data and operations across multiple government and regulatory authorities. It provides real-time access to vehicle registration, pollution certification, insurance status, and traffic violation records, enabling seamless coordination between departments such as the RTO, Traffic Police, Pollution Control Board, and Insurance Providers.
---
Features
RTO  can perform vehicle registration.
PCB can issue pollution certificate.
Insurance can create policy.
traffic department  add  challanas
traffic department can track vehicle
civil department can add complaints.
vehicle owner can view all details.
---
Installation
Install NetBeans IDE
Install Apache Tomcat Server
Install MySQL Database
Import the project into NetBeans
Add MySQL Connector JAR file
Configure database connection in the project
---
Usage
Run the project using Apache Tomcat
Open browser and go to:  
`http://localhost:8080/DigitalVahan/`
Select user role (Admin / RTO / Vehicle Owner / Insurance Company / PCB / Traffic Officer / Civil Police)
Perform operations like login, vehicle registration, create bid, place bid, apply insurance, add challan, pay challan, add complaints and view complaints
